Allo Router

What this site gets

The hosted dashboard is opt-in and off by default. Nothing reaches it until you run allo-router connect on a computer and approve that computer here.

Sent, per job

A hashed id (an HMAC made with a salt that never leaves your computer), when the job started rounded to the minute, the plan it went to as pool-1, pool-2 (the labels you typed stay on your computer), the plan type (subscription or API credit), the provider (ChatGPT, Claude Personal, Claude Team, Claude, Gemini, API or other), a short job title (from the task name, max 48 characters), the model and effort when those are set on the plan's run command, whether it ran, why it missed (from a fixed list), and the API value (est.) in USD, only when the tool reported token usage or cost.

Never sent

Prompts, commands, code, output, file names or paths, plan labels you typed, where a reading came from, token counts, your hostname or username, and API keys. The server rejects any upload with a field that isn't on the list above.

Plan readings, only if you opt in. With allo-router connect --share-readings on, uploads also carry each plan's % or $ left, its reset time and window (5-hour or weekly), when the reading was taken, and whether it was read automatically by allo-router sync or typed in with allo-router set. Plans are still numbered (pool-1, pool-2); labels and file paths never leave. --share-readings off stops it.

From your GitHub sign-in

Your GitHub user id and login, nothing else. The sign-in asks for no extra permissions.

How long it's kept

Job rows are deleted after 90 days. A computer's token stops working after 90 days without an upload.

Check it and stop it

allo-router connect --show prints exactly what the next upload would send, without sending it. Every upload is logged on your computer in ~/.config/allo-router/connect.log. allo-router disconnect revokes the token and deletes that computer's history here; Disconnect on the dashboard does the same. Delete my account removes everything.

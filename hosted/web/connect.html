Approve this computer?

Your terminal is waiting for approval to upload job summaries to your dashboard. Approve only if you just ran allo-router connect.

Check this matches the code in your terminal.

This computer shows on your dashboard as computer-1, computer-2 and so on, in the order you approve them.

What approving does. This computer gets an upload token. It can add job rows to your dashboard and nothing else: it can't read anything.

Each upload holds, per job: a hashed id, the minute it started, the plan as pool-1, pool-2, its type and provider, whether it ran, why it missed, and the API value (est.).

Never sent: job names, prompts, code, commands, output, file names or paths, plan names, readings or keys. allo-router connect --show prints the next upload without sending it; allo-router disconnect stops it.
